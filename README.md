# אמיקה — מקום לסקרנות

אתר תרגול בעברית לכיתה ב׳, שלב א׳ של מבחני המחוננים. 98 שאלות מקוריות, שש יחידות קצרות מדורגות ותרגול מסכם בן 26 שאלות. האתר כולל מדריך למלווה, טיימר אופציונלי, פתרונות, היסטוריה מקומית ודפי עבודה להדפסה. אין חשבונות, שרת נתונים או איסוף מידע.

## הפעלה

נדרש Node.js 20 ומעלה. היישום עצמו אינו תלוי בחבילות חיצוניות:

```sh
cd /workspace/stuff
npm start
```

השרת מאזין בפורט 3000. ניתן לבחור פורט באמצעות המשתנה `PORT`. זו הפעלה מקומית; לא בוצע פרסום לשירות אחסון ציבורי.

## גרסה עצמאית

```sh
npm run build
```

פותחים את `dist/amika.html` ישירות בדפדפן. כל התוכן, העיצוב והקוד כלולים בקובץ, ללא בקשות רשת. קישורי המקורות החיצוניים דורשים אינטרנט. השמירה המקומית תלויה בהרשאות הדפדפן; האתר מציג הודעה אם השמירה אינה זמינה. ניתן גם להעלות את הקובץ לאחסון סטטי.

## בדיקות

```sh
npm test
npm ci
# בחלון נפרד: npm start
npm run test:browser
```

בדיקת הדפדפן משתמשת ב־Chromium המקומי בנתיב `/usr/bin/chromium`; ניתן לקבוע `CHROMIUM_PATH`. היא בודקת תהליך תרגול, שמירת תשובות, סיום חלקי, היסטוריה, פקיעת זמן, הכנת דף עבודה, מקורות ומסכים צרים. קובצי צילומי מסך נכתבים ל־`/tmp`.

## תוכן ומגבלות

המודל מבוסס על דוגמאות שנקראו דרך מראה ציבורית, לאחר שגישה ישירה לאתרי המקור נחסמה. ראו [מחקר ומקורות](research.md). אין טענה להתאמה מלאה למבחן עתידי. כל הפריטים הותאמו לרב־ברירה, בעוד שבדוגמה הרשמית יש גם פריטים פתוחים. זמני התרגול הם המלצה פדגוגית, לא משך רשמי שאומת. הציון אינו אבחון או תחזית מעבר.

בדיקות עצמאיות של סוכנים נוספים מתועדות ב־[בדיקת קריאה](review-reading.md) וב־[בדיקת חשבון](review-math.md). הקושי נקבע לפי סוג החשיבה, אורך הקריאה ומספר שלבי הפתרון; הוא אינו מכויל פסיכומטרית.

היסטוריית התרגול והתשובות נשמרות ב־localStorage בדפדפן ובמכשיר בלבד. הטיימר משתמש בזמן סיום מוחלט, ולכן ממשיך לחלוף גם כשהעמוד סגור. אם חוזרים לתרגול לאחר שהזמן חלף, הוא מסיים ונבדק מייד. פתרונות נחשפים רק לאחר ההגשה. מחיקת ההיסטוריה דורשת אישור ואינה מוחקת תרגול שטרם הוגש.
